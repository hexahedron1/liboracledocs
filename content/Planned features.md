This list contains features that are planned for a future update or already in the works.
Feel free to suggest new features in the [GitHub repo's issues](https://github.com/hexahedron1/LibOracle/issues) or on the workshop thread.
Features higher on the list are likely to be released first.

| Feature                   | Description                                                                                                                    |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Custom broken arm pos<br> | Allow positioning the arm base in a completely arbitrary position and rotation when broken.                                    |
| Push to Meow event compat | Add an event for when the player meows.                                                                                        |
| Holding objects in hand   | Allow oracles to hold objects in their hand.                                                                                   |
| Hand positioning          | Allow positioning the hands arbitrarily.                                                                                       |
| Gate control              | Allow adding custom oracle-controllable gate locks with RegionKit                                                              |
| Controllable overseers    | Add an overseer-like entity that has no AI and can be controlled with code for cutscenes and such.                             |
| Pearl collection support  | Add support for saving read pearls into the downpour-exclusive collection menu                                                 |
| OracleGraphics wrapper    | A wrapper for OracleGraphics akin to [[OracleWrapper]] that is aimed to greatly simplify adding custom visuals to your oracle. |
| Forehead symbol           | Allow adding a forehead symbol to the puppet's graphics (like with LttM)                                                       |
