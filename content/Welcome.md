Welcome to LibOracle docs!
This website should guide you through using the library to create custom oracles.
If you're new to writing oracles or modding in general, it is recommended to first read through [Getting Started with modding](https://rainworldmodding.miraheze.org/wiki/Getting_Started) and [[Introduction]].

For the starting guide, see [[Your first oracle]].

If you have experience in writing oracles already and want to see the changes this library introduces, see [[What's different]].

For the list of planned/WIP features, see [[Planned features]].
